# Zahlenraten

Ein einfaches Zahlenspiel. 
Bei diesem denkt sich der Computer eine Zahl zwischen 1 und 100 aus.
Der Spieler muss diese erraten.
Die Anzahl der Versuche wird dabei gezählt.

## Benötigtes Programm.
Für die Ausführung des Spiels wird das Programm Eclipse IDE benötigt.

Für die Installation bitte auf den folgenden Link klicken:
https://www.eclipse.org/downloads/download.php?file=/oomph/epp/2026-06/R/eclipse-inst-jre-win64.exe

## Ausführen des Spiels.

Starten Sie eclipse.exe.
Klicken Sie oben rechts auf New Workbench.
Legen Sie unter "File" oben links ein neues Projekt an und erstellen Sie eine Klasse.
Kopieren Sie den Java-Code in das mittlere Fenster.
Klicken Sie auf "run".

## Achtung!
Der Name der Klasse muss NumberGuessGame sein!
